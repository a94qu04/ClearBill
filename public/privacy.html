ClearBill（清帳）隱私權政策

最後更新日期：2026-11-24

ClearBill（清帳）是一款以「本地優先（Local-First）」為核心設計的網頁記帳與分帳應用程式。我們高度重視您的資料隱私，本應用程式不設有任何後端伺服器，也不會蒐集、追蹤或上傳您的個人帳務資料至開發者伺服器。

1. 資料儲存方式

  • 您建立的所有專案、消費明細、成員與設定皆直接儲存於您個人裝置的瀏覽器本地資料庫（IndexedDB 與 localStorage）。
  • 您可隨時匯出本地 JSON 備份檔案，或透過瀏覽器設定清除本地資料。

2. Google 雲端硬碟（Google Drive）同步權限說明

  • 當您主動點選「Google 雲端硬碟備份／同步」功能並完成 Google 帳號授權時，ClearBill 僅會申請最小權限範圍：https://www.googleapis.com/auth/drive.file。
  • 此權限僅允許 ClearBill 在您自己的 Google 雲端硬碟中建立、讀取與更新本應用程式專屬的備份檔（clearbill-backup-v1.json），無法檢視、存取或修改您 Google 雲端硬碟中的任何其他檔案或資料夾。
  • 所有同步連線皆由您的瀏覽器直接與 Google 官方 API 溝通，存取權杖（Access Token）僅暫存於當次瀏覽器記憶體中，不會傳送給任何第三方。
  • 您隨時可在應用程式設定中點選「中斷連結」，或前往 Google 帳戶權限管理 撤銷 ClearBill 的存取權限。

3. 資料分享與第三方揭露

ClearBill 不會販售、出租或向任何第三方揭露您的使用者資料。本應用程式對 Google API 所取得資訊的使用與傳輸，完全遵守 Google API 服務使用者資料政策（Google API Services User Data Policy），包含「有限使用（Limited Use）」規定。

Privacy Policy (English Summary)

ClearBill is a local-first, serverless expense-splitting web application. All ledger data is stored exclusively in your browser's local storage (IndexedDB and localStorage). We do not operate a backend server and do not collect, track, or store your financial records.

  • Google Drive Sync: When you explicitly choose to sync with Google Drive, ClearBill requests only the minimal https://www.googleapis.com/auth/drive.file scope to read and update its own backup file (clearbill-backup-v1.json) stored in your own Google Drive. ClearBill cannot access any other files in your Google Drive.
  • Limited Use Compliance: ClearBill's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
